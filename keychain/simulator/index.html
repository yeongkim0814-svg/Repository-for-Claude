계측

1. 수면 방향 = 가속도계 값의 반대

가속도계는 f = a − g(비중력 힘)를 잰다. 키체인 안의 액체가 느끼는 유효중력은 g_eff = g − a = −f. 그래서 IMU 값의 부호만 뒤집어 그대로 "아래"로 쓴다. '떨어뜨리기'를 누르면 f ≈ 0이 되고, 아래 방향이 사라져 액체가 화면 전체로 흩어진다(디더링으로 표현).

시험 연결: 가속하는 버스 안 물컵 수면 tanθ = a/g, 엘리베이터 속 겉보기 무게 문제와 같은 식이다.

2. 매달린 키체인은 왜 잘 안 출렁일까

매달기 모드에서 고리를 흔들어도 수면은 기기 바닥과 거의 평행하다. 고정점 주위로 도는 강체에서 질량중심의 센서가 읽는 접선 성분은 (g_t + A_t)·k²/(k²+l²)로 줄어든다(k: 회전반경). l = 70 mm면 약 2%만 남는다. 이상적인 점 진자(k→0)라면 0이 되어 액체가 기기에 '붙어' 보인다.

고리 길이 l을 줄이면 이 비율이 커진다. 실제 펌웨어에서는 '기울기 게인'처럼 접선 성분을 과장해 연출하는 게 현실적인 해법이다.

시험 연결: 진자에서 장력과 중력의 합이 구심력이 된다. 진자 추 기준에서 겉보기 중력은 줄 방향이다.

3. CFL 조건과 병 크기 배율

얕은 물의 파속은 c = √(g h), 가장 느린 출렁임 주기는 T ≈ 2L/c. 실제 크기(S=1, 픽셀 0.17 mm)로는 T가 0.2~0.3초라 떨림처럼 보인다. 주기는 √(L/g)에 비례하므로 화면을 큰 병처럼 보이게 하려면 S를 키운다(프루드 상사).

명시적 적분은 c·Δt/Δx ≤ 1을 넘으면 발산한다. '서브스텝 자동'을 끄고 서브스텝을 줄이거나 S를 1로 낮추면 폭발하는 걸 볼 수 있다. MCU에서는 이 값으로 프레임당 서브스텝 수를 정한다.
