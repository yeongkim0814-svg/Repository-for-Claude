# 인게임 검증 체크리스트

`.pack` 을 설치한 뒤 순서대로 확인한다. 하나라도 실패하면 그 항목의 "실패 시" 열을 보고 고친 뒤
다시 빌드한다. 결과는 이 문서를 복사해 PR/이슈에 붙여도 된다.

## A. 로딩

| # | 확인 | 통과 기준 | 실패 시 |
|---|---|---|---|
| A1 | 설정 → Mods 에 팩이 보인다 | 이름/버전이 Pack Data 대로 표시 | `.pack` 위치와 폴더명 재확인 |
| A2 | 활성화 후 재시작해도 유지 | 체크 상태가 남아 있음 | 게임 로그 확인 |
| A3 | 빌드 화면 Engines 카테고리에 Meridian | 아이콘/이름 정상 | Pick Category 등록 |

## B. 빌드 화면

| # | 확인 | 통과 기준 |
|---|---|---|
| B1 | 부품을 집어 배치할 수 있다 | 드래그·스냅 정상 |
| B2 | 위쪽이 연료탱크에 붙는다 | 부착점 `(0, 0)` 이 탱크 바닥에 스냅 |
| B3 | 아래쪽에 분리기/구조물이 붙는다 | 부착점 `(0, -3)` 동작 |
| B4 | 폭이 스톡 2-wide 부품과 어긋나지 않는다 | 옆선이 맞음 |
| B5 | 텍스처가 늘어지거나 이음매가 튀지 않는다 | 세로 타일링 자연스러움 (Wrap Mode = Repeat) |
| B6 | 부품 정보창의 추력/ISP/질량 표시 | 60 / 330 / 5.0 |
| B7 | 대칭 배치·복사·회전 정상 | 스톡 엔진과 동일하게 동작 |

## C. 비행

| # | 확인 | 통과 기준 | 비고 |
|---|---|---|---|
| C1 | 점화된다 | 스로틀에 반응해 추력 발생 | 안 되면 `engineOn` 배선 |
| C2 | 화염이 노즐 끝에서 나온다 | 위치가 `(0, -3)` | 어긋나면 이펙트 위치 |
| C3 | 스로틀 0~100%가 선형으로 먹는다 | 중간 스로틀에서 화염 크기 변화 | |
| C4 | 연료를 소모한다 | 위쪽 탱크 게이지 감소 | `source` FlowModule |
| C5 | 연료 소진 시 자동 정지 | 추력 0, 화염 사라짐 | |
| C6 | 짐벌이 방향키에 반응 | 노즐이 좌우로 기울며 회전 토크 발생 | torque = throttle × 3 |
| C7 | 스테이징으로 분리된다 | 분리기와 함께 정상 분리 | |
| C8 | 연소 효율이 설계대로다 | 중형 전이단에서 Frontier 보다 확실히 오래 탐 | docs/01-design.md 3절 |
| C9 | 지구 이륙에는 부족하다 | T/W 가 낮아 뜨지 못함 — **의도된 동작** | |

## D. 저장·호환

| # | 확인 | 통과 기준 |
|---|---|---|
| D1 | 로켓을 저장하고 다시 불러온다 | 부품이 그대로 복원 |
| D2 | 비행 중 저장 → 로드 | 연료량·점화 상태 유지 |
| D3 | 스톡 부품과 섞어 쓴다 | 도킹포트·페어링·분리기와 충돌 없음 |
| D4 | 모드를 비활성화한 뒤 기존 세이브를 연다 | 게임이 죽지 않고 경고만 표시 |
