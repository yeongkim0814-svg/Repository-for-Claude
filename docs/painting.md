# 도색 가이드

단색으로 출력한 뒤 도색한다. 파츠를 분리해 출력해야 도색이 훨씬 쉽다.

## 색

| 부위 | 색 | 참고 |
|---|---|---|
| 몸통 | 민트 그린 | BMO의 상징색. 채도가 너무 높으면 장난감처럼 보인다 |
| 얼굴 창 테두리 | 진회색 ~ 검정 | 스모크 아크릴과 자연스럽게 이어지도록 |
| D-패드 | 진회색 | |
| 버튼 | 빨강 / 파랑 / 노랑 / 초록 | 원본 배치 그대로 |
| 다리·팔 | 몸통과 같은 민트 | |

## 순서

1. **출력물 표면 정리** — 서포트 자국을 사포(400 → 800)로 정리
2. **서페이서** — 회색 프라이머를 얇게 2~3회. 이 단계를 건너뛰면 도료가 벗겨진다
3. **몸통 본색** — 얇게 여러 번. 한 번에 두껍게 칠하면 흘러내린다
4. **버튼·디테일** — 별도 파츠로 칠한 뒤 조립
5. **마감** — 무광 또는 반광 클리어. BMO는 무광이 더 어울린다

## 주의

- **스모크 아크릴은 도색이 전부 끝난 뒤에 붙인다.** 도료나 먼지가 들어가면 지울 수 없다.
- 아크릴 보호 필름은 맨 마지막에 벗긴다.
- 아크릴 안쪽 면 중 화면 바깥 영역은 검정으로 막는다 (내부 부품이 비치지 않게).
- 도색 두께 때문에 끼워 맞춤이 뻑뻑해질 수 있다. 모델링 단계에서 **0.2mm 정도 여유**를 준다.
