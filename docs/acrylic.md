# 스모크 아크릴 창

## 왜 쓰는가

10cm BMO의 얼굴은 원본 비율대로면 가로 40mm 남짓인데, 우리가 쓰는 128×64 OLED는
그보다 작고 모양도 다르다. 패널 크기에 맞춰 구멍을 뚫으면 얼굴이 쪼그라들어 BMO처럼 안 보인다.

흑백 OLED는 자체발광이라 꺼진 픽셀이 **완전한 검정**이다(백라이트 LCD처럼 빛이 새지 않는다).
그래서 스모크 아크릴과의 궁합이 컬러 LCD보다 오히려 더 좋다 — 화면 꺼진 부분과 아크릴
뒤로 숨긴 여백이 색 차이 없이 완전히 하나로 붙는다.

해결책은 **개구부를 원본 비율대로 크게 뚫고 그 뒤를 스모크 아크릴로 덮는 것**이다.

- 꺼진 픽셀도, 화면 바깥 여백도 아크릴 뒤에서 **똑같이 까맣게** 보인다
- 패널의 실제 크기·베젤·나사 자국·배선이 전부 사라진다
- 켜진 도트만 어둠 위에 떠오른다 — 오히려 원본 애니메이션의 BMO 화면에 더 가까워진다

전자기기 외장에서 오래 쓰인 방법이고, 이 프로젝트에서는 "작은 화면을 큰 얼굴처럼 보이게 하는"
핵심 트릭이다.

## 규격

| 항목 | 값 |
|---|---|
| 두께 | 2mm |
| 투과율 | 20~30% (흑색 반투명 / "스모크") |
| 크기 | 얼굴 개구부보다 사방 2mm 크게 (안쪽 턱에 얹힌다) |

## 시공

1. 아크릴을 화면 표면에 **밀착시키지 않는다.** 1~2mm 띄운다.
   붙이면 뉴턴링(무지개 얼룩)과 무아레가 생긴다.
2. 아크릴 **안쪽 면** 중 화면이 안 보이는 영역은 검정 도색 또는 검정 시트지로 막는다.
   안 그러면 내부 부품이 비친다.
3. 고정은 얇은 양면테이프(사방 테두리)나 UV 레진. 접착제가 앞면으로 새면 지울 수 없으니 주의.
4. 보호 필름은 **조립 맨 마지막에** 벗긴다.

## 밝기 보정

아크릴이 빛을 먹으므로 백라이트를 높게 쓴다.

- 기본값 75% (`DEFAULT_BRIGHTNESS`)
- 웹앱의 밝기 슬라이더로 원격 조절 가능
- 수면모드에서는 8%로 떨어진다

## 반드시 먼저 해볼 것 (M2 단계)

**도색과 최종 출력 전에**, 아크릴 조각 하나를 손으로 화면 위에 들고 실제로 눈으로 본다.

- 너무 어두우면 → 표정이 흐릿하다. 투과율이 더 높은 판으로 교체
- 너무 밝으면 → 패널 테두리와 내부가 비친다. 더 어두운 판으로 교체

투과율을 잘못 고르는 것이 이 방식에서 가장 흔한 실패다. 판 값은 싸니 두세 종류를
같이 주문해 비교하는 편이 결국 빠르다.
