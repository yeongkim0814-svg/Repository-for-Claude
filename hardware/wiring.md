# 배선 — 납땜 없이 조립하기

이 프로젝트는 **납땜을 한 번도 하지 않는다**는 제약 위에 설계됐다.
연결은 세 가지 방법으로만 이뤄진다.

1. 이미 커넥터가 달려 나오는 부품 (서보)
2. 핀헤더 + 듀폰 점퍼선 (버튼, GND)
3. 드라이버로 조이는 스크류 터미널 (서보 전원)

## 부품

| 부품 | 비고 |
|---|---|
| ESP32-S3 + LCD 일체형 보드 | Waveshare ESP32-S3-LCD-1.47 계열. **핀헤더가 납땜되어 출고되는 상품인지 반드시 확인** |
| SG90 마이크로 서보 × 1 | 3핀 암 커넥터 기본 장착 |
| 택트 스위치 **모듈** × 2 | 생 스위치가 아니라 핀헤더 달린 모듈이어야 한다 |
| 암-암 / 암-수 듀폰 점퍼선 | |
| USB Type-C 암 → 스크류 터미널 브레이크아웃 | 서보 전원용 |
| 2포트 USB 충전기 (5V 2A 이상) | |
| 글루건 | 조립 마지막에 커넥터 고정 |

> 같은 보드라도 "핀 동봉(미납땜)" 옵션이 흔하다. 그걸 받으면 납땜 없이는 진행할 수 없으니
> 상품 사진에서 핀이 꽂혀 있는지 확인하고, 애매하면 판매자에게 물어본다.

## 핀맵

실제 핀 번호는 `firmware/include/board_config.h` 에 있다. 보드가 다르면 그 파일만 고치면 된다.

| 연결 | 보드 핀 | 상대편 |
|---|---|---|
| 서보 신호 | `PIN_SERVO` (기본 GPIO1) | SG90 주황선 |
| 서보 +5V | **보드 아님 — 스크류 터미널의 5V** | SG90 빨강선 |
| 서보 GND | 스크류 터미널의 GND | SG90 갈색선 |
| **공통 GND** | 보드 GND 핀 | 스크류 터미널 GND |
| 초록 버튼 | `PIN_BTN_GREEN` (기본 GPIO2) | 버튼 모듈 OUT |
| 파랑 버튼 | `PIN_BTN_BLUE` (기본 GPIO3) | 버튼 모듈 OUT |
| 버튼 전원 | 보드 3V3 / GND | 버튼 모듈 VCC / GND |

디스플레이는 보드에 붙어 있으므로 배선이 없다. 이것이 일체형 보드를 고른 이유다.

## 전원 — 왜 USB를 두 개 쓰는가

서보가 움직이기 시작하는 순간 전류를 크게 당겨서 전압이 순간적으로 떨어진다.
보드와 서보가 같은 전원을 쓰면 화면이 깨지거나 보드가 재부팅된다.
보통은 커패시터를 납땜해 해결하지만, 여기서는 **처음부터 전원을 나눠서** 그 문제를 만들지 않는다.

```
        ┌─ USB 케이블 1 ──→ [ESP32-S3 + LCD 보드]
2포트 ─┤                              │
충전기  └─ USB 케이블 2 ──→ [스크류 단자대] ─→ SG90 (빨강/갈색)
                                 │
                                 └─ GND ──── 보드 GND  ← 반드시 연결
```

**공통 GND를 빠뜨리면 서보가 아예 안 움직이거나 제멋대로 떨린다.** 가장 흔한 실수다.

## 버튼

실제로 배선하는 버튼은 2개뿐이다.

| 버튼 | 짧게 누름 | 길게 누름(5초) |
|---|---|---|
| 초록 | 수면모드 켜기/끄기 | — |
| 파랑 | 상태 화면 (WiFi / 신호세기 / MQTT) | WiFi 설정 포털 열기 |

나머지 D-패드와 컬러 버튼은 **모양만 있는 더미**다. 다만 케이스에는 모든 버튼 자리에
스위치 보스를 파두므로, 나중에 케이스를 다시 뽑지 않고 기능을 추가할 수 있다.

## 조립 마지막 단계

듀폰 커넥터는 흔들리면 빠진다. 동작을 확인한 **뒤에** 모든 커넥터 위에 글루건을 얹고
케이블을 케이블 타이로 정리한다. 이것이 납땜 없이 영구 조립하는 표준 방식이다.
