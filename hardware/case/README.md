# 케이스 — 기존 BMO 모델 개조

3D 모델을 처음부터 만들지 않고, 라이선스가 명확한 팬메이드 BMO 모델을 받아 개조한다.
외형 퀄리티를 빠르게 확보하고, 우리는 내부 구조에만 집중할 수 있다.

## 1. 원본 구하기

Printables 나 Thingiverse 에서 **CC-BY / CC-BY-SA 등 재배포 조건이 명확한** BMO 모델을 받는다.
받은 즉시 `CREDITS.md` 에 아래를 기록한다. (포트폴리오로 공개할 것이므로 출처 표기는 필수다)

- 모델 이름 / 제작자 / URL / 라이선스 / 받은 날짜

라이선스가 없거나 파생 금지인 모델은 쓰지 않는다.

**중요**: 다운받은 STL이 실제 BMO의 정답 외형이다. 화면 창 크기·버튼 위치·모양은
전부 원본을 그대로 따라간다 — 우리가 임의로 다시 정하지 않는다. 전자부품이 들어갈
자리만 안쪽에서 깎아 넣는다. 자세한 절차는 [`scripts/README.md`](scripts/README.md) 참고.

**현재 상태**: [Popandsicle의 "Adventure Time BMO Figure (Interactive)"](https://www.printables.com/model/1139445-adventure-time-bmo-figure-interactive)
에서 17개 파츠(전면판, 버튼 4종, D패드, 팔 2개, 다리 등)를 받아 `hardware/case/original/`
에 넣었다. `scripts/measure.py`로 전면판을 실측해 화면 베젤·버튼·D패드·나사 보스
좌표를 전부 확보했고([`features.json`](scripts/features.json)), 조립 설명서를
확인해 **버튼이 원래 스프링 장착식**이고 **팔은 원래 고정 핀(비가동)**이라는 것도
확인했다 — 자세한 내용은 [`CREDITS.md`](CREDITS.md) 참고.
**뒷판은 원본에 없어서 우리가 새로 설계**하기로 했다(전면판의 기존 체결 구멍 재사용).

## 2. 스케일

**앉은 자세 기준, 몸통(전면판) 높이 100mm**로 잡는다 — 다리는 앉아 있어서 높이에
거의 안 보태진다. 전면판 원본이 180mm이므로 축척 계수는 **0.556배**
(`scripts/features.json`의 `scale_to_target`에 기록됨). 비율 자체는 건드리지 않고
축 3개를 동일한 배율로 줄인다. 그 뒤 슬라이서에서 내부 치수를 실측해 아래 부품이
들어가는지 확인한다.

| 부품 | 대략 크기 |
|---|---|
| ESP32-S3 개발보드 + OLED 모듈 (SH1106/SSD1306) | 개발보드 약 25 × 50 × 8 mm, OLED 모듈 약 30 × 15 × 5 mm (모델별 확인) |
| SG90 서보 | 23 × 12 × 29 mm |
| 버튼 모듈 2개 | 각 12 × 12 × 8 mm |
| 듀폰 커넥터 + 케이블 다발 | **의외로 이게 제일 자리를 먹는다** |
| USB 스크류 단자대 | 약 20 × 15 mm |

납땜을 안 하는 대신 커넥터가 부피를 차지한다. 안 들어가면 **뒤판을 3~5mm 부풀린다.**
앞·옆 실루엣은 그대로라서 정면에서 보는 비율은 원본과 같다.

## 3. 개조 항목 — 전부 "안쪽에서만" 깎는다

바깥 표면(실루엣·화면 창 모양·버튼 돌기)은 절대 건드리지 않는다. `scripts/measure.py`
로 원본에서 화면·버튼의 실제 좌표를 뽑아낸 뒤, 그 좌표를 기준으로:

- **화면 자리 뒤쪽만** OLED + 스모크 아크릴 두께만큼 파낸다. 원본 화면 창 모양·크기는
  그대로 두고, 그 뒤에 스모크 아크릴을 붙인다 — 작은 OLED와 큰 화면 창의 차이는
  꺼진 픽셀이 완전한 검정으로 묻히는 것으로 해결한다 ([`docs/acrylic.md`](../../docs/acrylic.md)).
- **버튼 2개(실배선)**: 앞면은 그대로 두고, 그 돌기 바로 안쪽 벽에만 스위치 장착
  포켓을 판다. 나머지 버튼은 원본 그대로 손대지 않는다(전부 진짜 BMO 버튼처럼 보이고,
  2개만 눌렸을 때 스위치가 반응한다).
- **서보 마운트** + 원본의 팔 관절 소켓 위치에 맞춘 **팔 축 관통 홀** (3mm)
- **뒤판 분리** + M2 나사 보스 4개 (원본이 한 덩어리라면 새로 절개)
- **하단 개구부**: USB 케이블 **2가닥**이 나올 수 있게 (원본에 없는, 순수 기능용 절개)

이 작업은 손으로 슬라이서에서 하지 않고 `scripts/fit_internals.py` 로 좌표 기반으로
한다 — 반복 보정이 쉽고 무엇을 왜 깎았는지 기록이 남는다.

## 4. 반드시 거칠 단계

전체를 출력하기 전에 **속 빈 껍데기만 먼저 시험 출력**해서 부품을 넣어본다.
다 뽑고 나서 안 들어가는 것이 가장 흔하고 가장 아까운 실패다.
