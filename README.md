# 흐르는-직선(flow-line) 시간지연 모델

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/yeongkim0814-svg/Repository-for-Claude/blob/claude/time-delay-model-design-f8jlrj/flow_line_model.ipynb)

낮은 차원에서 출발한 시간 지연 모델을 형식화하고, Schwarzschild 해 및
Newton 중력과 수치로 비교한다. 위 배지를 누르면 설치 없이 바로 코랩에서
실행할 수 있다 (`flow_line_model.ipynb`).

## 모델

**1차원 구성.** 직선(선분) 위에 점이 하나 있다.

- 점은 **직선의 정지계에서** 속력 `u` 로 직선을 따라 한 방향으로 나아간다.
- 직선은 자기 자신과 평행하게, 속력 `w` 로 평행이동한다. 방향은 점의
  진행과 반대, 즉 천체 쪽(안쪽)이다.
- 점이 **직선 눈금 위에서 나아간 거리**가 시계 눈금이다.

정지한 직선(무한원, `w=0`)에서의 진행거리와 움직이는 직선(반지름 `r`)에서의
진행거리의 비를 `t(r)/t(∞)` 와 같다고 놓고, 이를 만족하는 `w(r)` 를 구한다.

## 측정 규약 — 결과를 좌우하는 갈림길

"일정 시간 동안 나아간 거리"는 아직 미결정 표현이다. 어느 계에서 시간을
재고 어느 계에서 거리를 재느냐에 따라 네 가지로 갈라진다.

| 규약 | 무엇을 재는가 | 비 | u 의존 | 판정 |
|---|---|---|---|---|
| A | 실험실계 좌표에서 잰 점의 변위 | `(1 - w/u)/(1 - uw/c²)` | 의존 | 기각 |
| **B1** | **직선 고유시계로 잰 경과시간 동안의 눈금 진행거리** | **`√(1 - w²/c²)`** | **무관** | **채택** |
| B2 | 점의 도착 사건을 직선 좌표로 읽음 | `√(1 - w²/c²)/(1 - uw/c²)` | 의존 | 기각 |
| C | B1 의 눈금거리를 실험실계에서 읽음 | `1 - w²/c²` | 무관 | `g_tt` 자체 |

**B1 을 채택하는 이유:** 시간 지연은 "무엇으로 재느냐"에 의존하면 안 된다.
`u` 가 소거되는 규약은 B1 과 C 뿐이고, C 가 주는 `1 - w²/c²` 는 계량 성분
`g_tt` 이지 시간 지연 `√g_tt` 가 아니다.

**B2 를 주의할 것:** "점이 도착한 사건"을 기준으로 직선 좌표를 읽으면 동시성의
상대성 때문에 Doppler 인자 `1/(1 - uw/c²)` 가 섞여 들어와 비가 1 을 넘는다
(시간이 빨리 가는 셈). `u=c` 에서는 정확히 `√((1+β)/(1-β))` 가 되어, 1 보다
작은 시간 지연 비를 아예 만들 수 없다.

네 규약 모두 손으로 정리한 공식이 아니라 **명시적 Lorentz 부스트**에서
유도하고, 그 둘이 일치하는지를 검사한다 (`test_consistency_check`).

## 결과

B1 로 `w` 를 역산하면

```
√(1 - w²/c²) = √(1 - r_s/r)   =>   w(r) = √(2GM/r) = 그 지점의 탈출속도
```

이는 **약한장 근사가 아니라 전 영역에서 정확한 항등**이다. 이 흐름장에서

| 양 | 모델 | 기존 이론 |
|---|---|---|
| 시간 지연 | `√(1 - w²/c²)` | Schwarzschild `√(1 - r_s/r)` |
| 포텐셜 | `Φ = -w²/2` | Newton `-GM/r` |
| 중력장 | `g = w·dw/dr` (흐름의 이류 가속도) | Newton `-GM/r²` |
| 지평선 | `w = c` 인 지점 | `r = r_s` |

지평선은 가정이 아니라 **결과**로 나온다. `w > c` 가 되면 점이 `u ≤ c` 로는
바깥으로 진행할 수 없다.

이 그림은 **Painlevé–Gullstrand 좌표계 / river model of black holes**
(Hamilton & Lisle, 2008) 과 같은 구조다. 즉 이 모델은 새 이론이 아니라,
정합적 이론의 1차원 축소판에 도달한 것이다.

## 1차원이 스스로 낳지 못하는 것

1차원 구성만으로는 `w` 의 `r` 의존성이 나오지 않는다. 그것은 3차원 닫힘
조건에서 온다:

```
진공에서  ∇²(-w²/2) = 0,  w(∞) = 0   =>   w² = 2GM/r
```

`w ∝ r^(-1/2)` 를 고정하는 것은 이 Laplace 방정식이다. 위 표의 역산은
Schwarzschild 답을 알고 되짚은 것이므로, 순방향 예측은 반드시 이 닫힘
조건에서 출발해야 한다. 코드는 두 방향을 분리해 둔다
(`calibrate_flow_speed` vs `flow_speed` 이하).

## 한계

1. **횡방향/궤도 운동이 없다.** 1차원 반경 슬라이스만 담으므로 빛의 휘어짐,
   근일점 이동은 나오지 않는다. 완전한 PG 계량
   `ds² = -c²dt² + (dr + w dt)² + r²dΩ²` 로 확장해야 한다.
2. **선호 기준계(에테르) 그림이다.** 흐름이 국소적으로 검출 불가능함을
   따로 보여야 한다 (Michelson–Morley 2차 항 소거).
3. **회전 천체(Kerr)** 에는 비틀림이 있는 흐름이 필요하다.
4. **"거리비 = 시간비" 는 정의이지 유도가 아니다.** 왜 시계가 그 양을
   재는지에 대한 논거가 다음 과제다.
5. `r < r_s` 에서 `w > c` — 공간 흐름은 좌표 효과라 가능하지만 신호는 불가.

## 정밀도

## 구성

```
flow_line_model.ipynb   코랩 노트북 (설치 없이 바로 실행)
flowline/
  constants.py    물리 상수, 가상 천체 정의
  kinematics.py   1차원 구성의 순수 특수상대론 부분 (부스트, 네 규약, 역산)
  theory.py       비교 대상 (Schwarzschild, Newton)
  model.py        역방향 교정 / 순방향 예측, Φ, g, 지평선, 진공 닫힘
  checks.py       정합성 검사 10종 (BODIES 순회는 _max_over_bodies 로 공유)
  report.py       비교표 3종 (BODIES 표는 _body_table 골격 공유)
  plots.py        그림 3종 (스크립트/노트북 겸용 백엔드 처리)
run_all.py        CLI 진입점
tests/            pytest 스위트
```
