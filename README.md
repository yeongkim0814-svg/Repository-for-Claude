# BMO — 원격 조종 피규어

한국에서 인터넷을 통해 **표정과 팔을 원격으로 움직일 수 있는** 높이 10cm짜리 BMO
(Adventure Time) 피규어. 말레이시아 기숙사에 있는 사람에게 보내기 위해 만들었다.

```
[브라우저 웹앱] ──MQTT/WSS──> [브로커] ──MQTT/TLS──> [BMO]
  GitHub Pages                 HiveMQ 무료          ESP32-S3
  (서버 없음)                                        기숙사 WiFi 뒤
```

## 할 수 있는 것

- 내장 표정 10종 전환 (기쁨 / 하트 / 윙크 / 삐짐 …)
- 태블릿에서 **직접 그린 그림**을 BMO 화면에 띄우기
- **한글 글씨** 보내기 (브라우저가 도트로 구워 보내므로 기기에 한글 폰트가 필요 없다)
- 양팔 각도 조절 + 손 흔들기 / 안아주기 / 만세
- 수면모드, 화면 밝기 원격 조절
- 아무도 안 볼 때도 혼자 눈을 깜빡이고, 시선을 옮기고, 하품한다

## 설계에서 중요한 것들

**얼굴은 비트맵 묶음이 아니라 파라미터다.** 눈 뜬 정도·시선·입 모양을 숫자로 들고 있어서
표정 사이를 부드럽게 보간할 수 있고, 그 위에 아이들 모션을 겹쳐 얹을 수 있다.
자연스러움은 해상도가 아니라 타이밍에서 나온다 — 깜빡임은 감길 때 빠르고 뜰 때 느리며,
간격이 랜덤하고, 가끔 두 번 연속으로 깜빡인다.

**스모크 아크릴이 외형을 만든다.** 얼굴 개구부를 BMO 원본 비율대로 크게 뚫고 그 뒤를
반투명 흑색 아크릴로 덮으면, 꺼진 픽셀과 화면 바깥 여백이 똑같이 까맣게 보인다.
실제 패널은 작지만 얼굴은 원본 비율 그대로다. ([자세히](docs/acrylic.md))

**납땜을 한 번도 하지 않는다.** 디스플레이 일체형 보드, 커넥터 달린 서보, 버튼 모듈,
스크류 단자대만 쓴다. 서보의 전압 강하 문제는 커패시터 대신 **전원을 처음부터 분리**해
회피한다. ([자세히](hardware/wiring.md))

**서버가 없다.** 기숙사 WiFi는 방화벽 뒤라 밖에서 들어갈 수 없으므로, BMO가 밖으로
브로커에 붙어 있는다. 웹앱은 정적 파일이고 브라우저에서 직접 같은 브로커에 붙는다.

## 구조

```
firmware/     ESP32-S3 펌웨어 (PlatformIO / Arduino)
  include/board_config.h   핀·패널 설정 — 부품을 바꾸면 여기만 고친다
  src/face/                64x48 렌더러 + 표정 애니메이터
  src/arm/                 서보 (이징 구동, 자동 detach)
  src/ui/                  버튼 2개
  src/net/                 WiFi 프로비저닝 · MQTT · 그림 코덱
webapp/       정적 웹앱 (MQTT.js) — GitHub Pages 배포
hardware/     배선 · 케이스 개조 메모
docs/         설정 · 조립 · 도색 · 프로토콜
```

## 시작하기

1. [`docs/setup.md`](docs/setup.md) — 브로커 만들기, 펌웨어 올리기, WiFi 넣기
2. [`hardware/wiring.md`](hardware/wiring.md) — 부품과 배선 (납땜 없음)
3. [`docs/assembly.md`](docs/assembly.md) — 조립 순서
4. [`docs/protocol.md`](docs/protocol.md) — MQTT 토픽과 그림 포맷

```bash
cd firmware && pio run          # 펌웨어 빌드
cd webapp && python3 -m http.server 8000   # 웹앱 로컬 실행
./tools/test_codec.sh                       # 그림 코덱 왕복 테스트 (JS 인코더 ↔ C++ 디코더)
```

## 상태

| 단계 | 상태 |
|---|---|
| M1 펌웨어 뼈대 | 코드 작성 완료 (실기기 검증 전) |
| M2 얼굴 렌더러 · 아이들 모션 | 코드 작성 완료 (실기기 검증 전) |
| M3 서보 · 버튼 | 코드 작성 완료 (실기기 검증 전) |
| M4 WiFi · MQTT | 코드 작성 완료 (실기기 검증 전) |
| M5 웹앱 | 코드 작성 완료 (실기기 검증 전) |
| M6 케이스 · 도색 | 3D프린터 대기 |
| M7 현지 배치 | — |

부품이 도착하기 전이라 **아직 실제 하드웨어에서 돌려보지 않았다.** 핀 번호와 패널 규격은
구매한 보드에 맞춰 `firmware/include/board_config.h` 에서 맞춰야 한다.

## 자격증명

WiFi 계정, MQTT 비밀번호 등은 리포지토리에 넣지 않는다.
기기 설정은 NVS에, 웹앱 설정은 브라우저 localStorage 에만 저장된다.
